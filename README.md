# Advanced Transit Detection System  
  
## Описание проекта  
Данный проект представляет собой многоуровневый конвейер (пайплайн) компьютерного зрения для захвата, трекинга и фильтрации объектов в реальном времени. Проект завернут в микросервис на FastAPI и спроектирован так, чтобы минимизировать нагрузку на железо (учитывая изначальную разработку под Edge-устройства на NPU процессорах).  
  
Она просеивает видеопоток (находящийся в движении, с разными ракурсами), захватывает объекты, фильтрует смазанные и темные кадры, а затем отправляет единственную идеальную фотографию объекта ("Best Shot") в стороннюю базу.  

### Запуск

Вы можете запустить демонстрационную версию проекта прямо через GitHub. Система автоматически обработает ваш запрос, запустит вычисления в нашей облачной инфраструктуре и предоставит результат.

### Как запустить демо:

1.  **Создайте обращение (Issue):** Перейдите во вкладку [Issues](../../issues) и нажмите **New Issue**. Вы также можете использовать любое уже открытое вами обращение.
2.  **Отправьте команду:** В поле комментария напишите строго следующую команду:
    ```text
    /run-demo
    ```
3.  **Дождитесь ответа бота:** Наш бот подтвердит получение команды. Запуск и обработка данных обычно занимают меньше минуты.
4.  **Получите результат:** * Бот пришлет уведомление о завершении в комментариях.
    * Перейдите во вкладку [Actions](../../actions), выберите последний успешный запуск **Trigger Private Demo** и скачайте артефакт `public-demo-results` в нижней части страницы.

> [!IMPORTANT]
> Демо-версия работает на ограниченных ресурсах. Если вы не получили ответ в течение 5 минут, пожалуйста, попробуйте отправить команду повторно.

## Как скачать результаты?  

### Шаг 1: Перейдите на страницу Actions  
Откройте в браузере:  
👉 https://github.com/Artyom743/demo_ui/actions  

### Шаг 2: Найдите последний запуск    
* В списке workflow выберите "Trigger Private Demo"  
* Нажмите на самый верхний (последний) запуск  

### Шаг 3: Скачайте артефакт  
* Прокрутите страницу вниз до секции "Artifacts"  
* Нажмите на public-demo-results.zip  
* ZIP-архив с результатами скачается на ваш компьютер

### Шаг 4: Распакуйте и смотрите  
Внутри архива — Результаты обработки (изображения с выделенными лицами)
